GTFS editor

edit.gtfs.zone is a browser-based GTFS transit data editor. All data stays in your browser. No server, no account required.

  • Load a feed: from a URL or a local GTFS zip file.
  • Edit any table: agencies, routes, stops, trips, stop times, calendars, fares, and every other file.
  • Place stops on the map: add and position stops directly on the map.
  • Check the feed: validate against the GTFS Schedule spec as you go.
  • Export a zip: download a ready-to-publish GTFS feed.

Part of gtfs.zone, open source tools for GTFS and GTFS Realtime. See the GTFS Schedule reference.
